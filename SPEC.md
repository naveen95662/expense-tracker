# Expense Tracker API

A small REST API to record expenses and see spending totals by category.

## Tech
- Python 3.12, FastAPI
- Storage: DynamoDB (table name from env var TABLE_NAME)
- Runs in a Docker container on port 8000

## Data model (Expense)
- id (uuid, generated by the server)
- amount (number, must be > 0)
- category (string, e.g. food, travel, rent)
- description (string, optional)
- date (YYYY-MM-DD, defaults to today)

## Endpoints
- POST   /expenses           create an expense
- GET    /expenses           list expenses (optional ?category= filter)
- DELETE /expenses/{id}      delete an expense
- GET    /expenses/summary   total amount per category
- GET    /health             returns {"status": "ok"}

## Requirements
- Validate input (reject negative or zero amounts, missing category)
- Return proper HTTP status codes (201, 404, 422)
- Unit tests with pytest (use a mock or in-memory store, no real AWS in tests)
- Dockerfile (small image, non-root user)
- Log each request as JSON to stdout
- No secrets in code; config via environment variables
- README with how to run locally and how to run tests
